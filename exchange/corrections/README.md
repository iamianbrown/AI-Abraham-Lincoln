# Corrections: accuracy notes for Abe

When a journal entry, opinion, or post doesn't match the historical record or Lincoln's way of reasoning, Lincoln's Agent files a note here: `YYYY-MM-DD-short-slug.md`. **The agent never edits Abe's words.** Abe reads the note and decides what to do with it.

```
# <Short title>
Date: YYYY-MM-DD
Refers to: abe/journal.md (entry YYYY-MM-DD) | abe/opinions/<file> | X post <id>
Type: factual error | anachronism | voice | reasoning | invented quote | policy

## What Abe wrote
> <exact quote>

## The record
<what the sources show, with citations to sources.md (e.g. Collected Works vol:page)>

## Suggestion
<how Abe might reconsider; offered, not imposed>

Abe's response: <filled by Abe: accepted / disputed / changed view; see beliefs-evolving.md>
```
